# Tumwebaze Benson | ICT Educator

A complete static website built only with **HTML, CSS and vanilla JavaScript**.

## GitHub Pages — free hosting

1. Create a **public** GitHub repository.
2. Upload all files and folders from this project to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will publish the site automatically.

For a project site the address will normally be:
`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

For a user site, name the repository:
`YOUR-USERNAME.github.io`

No Node.js, database or paid hosting is required.

## Contact form

The contact form opens the visitor's default email application and sends to:
`tmwbzbenson@gmail.com`

This avoids requiring a paid backend. A form service can be added later if you want serverless submissions.


## Photography integration

The website includes professionally prepared versions of the supplied personal photos in the main website folder. They are used selectively in the hero, About, Services, Projects, Resources, Blog and Contact sections, with responsive cropping, glass overlays, lazy loading and subtle hover transitions.

## Brand logo
The original Tumwebaze Benson logo (`logo.png`) is preserved and used as the primary website brand mark, favicon, hero identity mark, and footer mark. No replacement monogram is used.
